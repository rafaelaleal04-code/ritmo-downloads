# Ritmo para Android

[Baixar o APK mais recente](https://github.com/rafaelaleal04-code/ritmo-downloads/releases/latest/download/Ritmo.apk)

Abra o link no Android e instale por cima da versão anterior, sem desinstalar. Recomendamos exportar um backup antes de atualizar.

A partir da versão 1.1.0, use **Configurações → Aplicativo → Buscar atualização**. Nas instalações que ainda exibem **Evolução**, busque a primeira atualização por essa aba. Melhorias compatíveis são baixadas pelo Ritmo; mudanças que exigem uma nova instalação abrem o download do APK, com confirmação do Android.

Este repositório contém somente instaladores e informações de versão. O código-fonte permanece privado. Nenhum histórico de treino ou registro de peso é publicado aqui.
